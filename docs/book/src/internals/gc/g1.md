# G1

G1 是分代 + 分区回收器，目标是控制暂停时间。这一章说明它在 wjsm 中的实现。

## 分区

G1 把堆划分成固定大小的分区（region）。每个分区可以在 young 和 old 之间切换。分配优先在 young 分区进行，young 分区满时触发 young GC。

分区粒度让 G1 可以选择性地回收部分分区，而不是整个堆。回收集（collection set, CSet）是本次 GC 要回收的分区的集合。

## 分代

- **young 分区**：新分配对象，GC 频繁回收。
- **old 分区**：经历多次 young GC 仍存活的对象，晋升而来。
- **mixed GC**：回收整个 young 分区 + 部分 old 分区，用于治理 old 区碎片。

young GC 只扫 young 分区 + remset 记录的跨代引用，暂停时间与 young 区大小相关，不受整个堆大小影响。

## 暂停时间控制

G1 根据用户设定的暂停时间目标（`--gc-g1-max-pause-ms`）选择 CSet 大小。它记录每个分区的回收成本估计，在目标时间内尽可能多回收分区。

## 写屏障

G1 使用写屏障维护 remset。old 对象写入 young 对象引用时，记录到 old 分区的 remset。young GC 扫描 CSet 内对象 + CSet 外对象在 remset 里记录的引用。
